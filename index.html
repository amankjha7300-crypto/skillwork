Full-Stack Next.js + FastAPI App

Why does VS Code "Go Live" look like this?

VS Code's "Go Live" extension only runs a static server on port 5500. This project requires the Next.js and FastAPI development servers to run.

How to run the application

  1. Open your file explorer or terminal inside skill-work-platform.
  2. Double-click start.bat (or run it in terminal).
  3. It will launch both the backend (port 8000) and frontend (port 3000) and open your browser automatically!
Open App (http://localhost:3000) → API Docs (Swagger)
